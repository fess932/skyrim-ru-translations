---
description: Перевести мод на русский: сервер прогресса, порции, параллельные агенты, сборка DSD
argument-hint: <slug мода из mods/> [кол-во агентов, по умолчанию 4]
---

Переведи мод `mods/$1` (параллельно агентов: `$2`, если не задано — 4). Работай из корня репозитория.

1. **Сервер прогресса.** Проверь `curl -s http://127.0.0.1:8765/api/status`. Если не отвечает —
   запусти `python tools/serve.py` в фоне (run_in_background). Дай пользователю ссылку
   http://localhost:8765 одной строкой.

2. **Подготовка.** Сначала поищи в интернете готовый русский перевод мода и скажи о нем пользователю. Если нет `work/$1/batches/`:
   - если нет `vanilla/names.json` — спроси путь к `Data` игры и запусти `tools/vanilla_dict.py`, затем `tools/lore_terms.py`;
   - для каждого плагина из `mods/$1/mod.json` → `tools/extract.py` в `work/$1/en/<Plugin>.json`
     (путь к плагину возьми из mod.json `plugin_paths` или спроси);
   - `python tools/prepare.py mods/$1`.

3. **Перевод.** `python tools/next.py mods/$1` покажет оставшиеся порции. Пока они есть:
   - возьми следующие N порций, для каждой выполни `python tools/next.py mods/$1 <NNN>`
     (задание пишется в `work/$1/tasks/<NNN>.md` — так сервер покажет её «в работе»);
   - запусти N агентов одновременно (одним сообщением). Каждому: «Прочитай задание
     `work/$1/tasks/<NNN>.md` целиком и выполни его: переведи все строки и запиши ответ в
     `work/$1/out/<NNN>.json` как JSON-объект {id: перевод}. Пиши файл частями, если он большой
     (Write, затем Edit с дописыванием), но итог — один валидный JSON. Потом запусти
     `python tools/validate.py work/$1/batches/<NNN>.json work/$1/out/<NNN>.json` и исправь
     все строки, которые он показал, пока не будет 0 ошибок. Ответь одной строкой: сколько ок.»;
   - задания на следующие порции генерируй только после того, как предыдущие готовы —
     тогда память переводов (`tm.py`) подхватит уже готовые строки.
   - Первые 1–2 порции переведи сам, без агентов: они задают стиль для памяти переводов.

4. **Единообразие.** `python tools/consistency.py mods/$1` — термины словаря, переведенные
   иначе, чем в словаре. Явные расхождения поправь в `work/$1/out/*.json`.

5. **Сборка.** `python tools/build.py mods/$1`. Если в `work/$1/build_report.txt` есть
   MISSING/INVALID — дозакажи эти строки агенту или исправь сам, пересобери.

6. **Выборочная вычитка.** Прочитай 30 случайных пар EN→RU из итогового `RU.json`: термины,
   «ты»/«вы», род героя, теги. Явные ошибки исправь в `work/$1/out/*.json` и пересобери.

7. **Коммит.** Отдельным коммитом только `mods/$1/` (переводы), сообщение
   «<Имя мода> <версия>: русский перевод (N строк)». Пуш — если пользователь не против.

8. **Остановить сервер прогресса**, если его запускала эта команда (TaskStop фоновой задачи
   `serve.py`): после сборки страница больше не нужна.

Правила стиля — в `prompts/translate.md`; не переписывай их без просьбы пользователя.
